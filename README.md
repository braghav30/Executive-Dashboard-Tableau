# 📊 Executive Sales Dashboard – Tableau

## 🔎 Project Overview

This project presents an **Executive-Level Sales Dashboard** built using **Tableau** with the Sample Superstore dataset.

The dashboard provides senior leadership with a high-level business performance overview, focusing on profitability trends, regional sales distribution, and key executive KPIs.

The report is interactive and allows users to filter and analyze performance across different product categories and regions.

🔗 **Live Dashboard (Tableau Public):**

---

## 🎯 Business Objective

The primary objective of this dashboard is to:

- Monitor overall business performance
- Track weekly profitability trends
- Identify region-wise sales contribution
- Provide quick KPI insights for executives
- Enable category-level performance filtering

---

## 📌 Key Performance Indicators (KPIs)

The dashboard includes the following executive KPIs:

- **Total Sales**
- **Total Profit**
- **# Orders**
- **# Customers**

All KPIs dynamically update based on selected filters.

---

## 📈 Visualizations Used

### 1️⃣ Weekly Profit Trend Analysis

- Line Chart: **Week vs Profit**
- Displays weekly profit performance
- Includes a **6-Week Moving Average**
- Helps identify short-term trends and performance momentum
- Useful for spotting volatility and profit stability

### 2️⃣ Region-wise Sales Distribution

- Visual representation of sales contribution by region
- Enables quick comparison of regional performance
- Supports strategic regional decision-making

---

## 🎛 Filters Implemented

The dashboard includes interactive filters:

### Category Filter
- Filters KPI metrics
- Enables performance analysis by product category

### Region Filter
- Filters chart-level visuals
- Helps compare and isolate regional trends

All filters are designed to provide an intuitive executive-level user experience.

## 🛠 Tools & Techniques Used

- Tableau Desktop
